# A股市场宽度 + BTI 回测系统

这是一个可本地运行的 Streamlit 回测工具。它不内置虚构行情；只有上传真实 CSV 后才会生成实际结果。默认支持：

- 用个股日线计算“收盘价高于SMA50的股票占比”；
- 从每日上涨/下跌家数计算 EMA10 广度指标；
- 研究策略：近20个交易日出现过宽度低于10%，随后宽度从10%或以下重新上穿10%；可选要求BTI确认；
- 信号日收盘确认，下一交易日开盘买入，持有5或20个交易日后收盘退出；
- 可编辑手续费和滑点假设，导出交易、净值曲线和质量报告。

## 安装运行

建议 Python 3.10–3.12。

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

浏览器打开 Streamlit 输出的本地地址即可。

## 输入文件格式

### A. 股票级日线 CSV（推荐）

必需字段：

```csv
date,code,close
2024-01-02,600000.SH,7.25
2024-01-03,600000.SH,7.31
```

建议增加 `open,high,low,volume,amount`；如已提供一致复权口径的 `adj_close`，系统会优先用它计算均线。每一行是一只股票的一个交易日。输入中应尽量包括当时真实上市的股票、后来退市的股票和历史纳入状态，以减少幸存者偏差。

### B. 预计算宽度 CSV

必需字段：`date,breadth_pct`。若使用BTI确认，还应提供 `advancers,decliners` 或 `ad_ratio_pct`。此模式不能独立复核宽度公式，必须保留数据来源和计算说明。

### C. 执行标的日线 CSV

必需字段：`date,open,close`；建议 `high,low,volume,amount`。应优先上传真实可交易的宽基 ETF 日线。若上传指数数据，结果只是指数代理，不是可实际成交的策略收益。

## 指标和信号定义

### 市场宽度

对每只股票计算滚动SMA50。只有具备50个有效观测值的股票才进入当日分母：

`breadth_pct = 100 × 当日收盘价高于SMA50的有效股票数 / 有效股票总数`

### BTI

默认提供标准 Zweig Breadth Thrust 的近似计算：`EMA10(上涨家数/(上涨家数+下跌家数))`，并使用百分数刻度；当指标在近10个交易日出现过不高于40的值，随后从不高于61.5上穿61.5时确认。由于不同软件的初值、上涨/下跌家数口径和阈值细节可能不同，此实现并不自动等于截图原始BTI。也可选用“EMA10上穿40”的自定义代理，或关闭BTI过滤。

### 买卖

- 近20个交易日（不含当前日）宽度曾低于10%；
- 当前日宽度从前一日不高于10%收复至10%以上；
- 可选要求BTI确认；
- 信号日收盘后才能确定信号，下一交易日开盘买入；
- 持有5或20个目标标的交易日，第N日收盘退出；
- 持仓重叠时不重复开仓；
- 净收益按单边手续费+滑点在买入和卖出各扣一次。

该策略是研究基线，不是投资建议；所有阈值应先登记，再进行样本外检验，不能根据测试集收益反复调参。

## 数据正确性门槛

1. 检查 `date+code` 重复记录、缺失价格、非正价格、日期范围和证券覆盖。
2. 使用历史点时股票池，纳入后来退市股票；只用当前上市股票会产生幸存者偏差。
3. 均线价格必须处理分红、送转等公司行为。不要对已复权价格重复复权。
4. 对照可信来源逐日抽样核验宽度、涨跌家数、交易日历和异常日期。
5. 交易标的要使用实际可交易的开盘/收盘价格，并对涨跌停、停牌、成交量和交易费用进行进一步约束。当前引擎的成交可行性仍需根据输入数据完善，不能视为券商级成交模拟。
6. 将5日、20日分开测试；报告信号数、胜率、单笔均值/中位数、最大回撤、波动率、夏普、成本敏感性和基准差异。
7. 保留原始CSV、来源、下载时间、哈希值、参数JSON和代码版本。

## 当前已知限制

- 不自动下载完整历史行情；本系统不假装已获取全量A股数据。
- 无法仅凭截图精确恢复每日蓝线和原图BTI公式。
- 股票池是否包含历史退市股取决于用户提供的数据。
- 默认按目标标的日线建模，未完整模拟A股涨跌停无法成交、停牌延迟、最小交易单位和税费变化。
- 标准BTI为近似实现，应与原始公式分开报告。
